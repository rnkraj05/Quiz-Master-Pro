# QuizMaster Pro

QuizMaster Pro is a responsive Online Quiz Maker web application developed using HTML, CSS and JavaScript.

It allows users to create quizzes, take quizzes, view results and track their performance through an interactive and user-friendly interface.

## Features

* Responsive Home Page
* Quiz Categories
* Dynamic Quiz System
* Quiz Creation Form
* Quiz Participation
* Automatic Score Calculation
* Results Dashboard
* Progress Bar & Performance Analysis
* Login & Registration UI
* Mobile Responsive Design
* Modern User Interface

## Pages

* Home Page

* Create Quiz Page
